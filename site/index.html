卡片資料

網站的卡片資料由排程每兩週（週日晚上）自動更新：抓取簡中官網 onepiece-cardgame.cn 的全部卡片，簡中還沒收錄的卡再從繁中官網、日版官網補進來（卡片格右下角會標「繁」「日」），產生的 cards.json 與 index.html 一起部署，打開網站就會自動載入。

下面的手動流程只在等不及排程或在本機 file:// 使用時才需要（只會抓簡中官網）：

  1. 按「複製抓取腳本」。
  2. 用 Chrome 打開 onepiece-cardgame.cn/cardlist，按 F12 開啟開發者工具 → Console。
  3. 第一次貼上時 Chrome 會先擋下並顯示警告，照它要求在 Console 輸入 允許貼上（英文版 Chrome 是 allow pasting）按 Enter，然後再貼一次腳本按 Enter。左上角會顯示進度，約 2～3 分鐘後自動下載 cards.json。
    腳本只做三件事：讀官方的卡片清單 API、逐張讀卡片詳情、把結果打包成 JSON 下載到你電腦；不會讀取 Cookie、帳號或送資料到別處。
  4. 只更新這台瀏覽器：把 JSON 拖進下方或點選檔案（下次排程部署的資料若比較新，開啟時會自動換回）。
    更新網站：到 GitHub repo 的 Actions 手動執行「Update card data」即可，不用再拖檔案到 Netlify。
把 JSON 檔拖到這裡

匯入會整個覆蓋瀏覽器裡的卡片資料（自訂卡與牌組不受影響）。若網站的 cards.json 比瀏覽器裡的新，開啟時會自動換成新的。

匯入／匯出牌表

格式：每行一張，4x OP17-002 或 OP17-002 x4 都可以；領袖請寫在第一行或標「領袖」。
